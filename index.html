CIPHER INVESTIGATION BOARD — A / B / C / D

ココフォリア・スクリーンパネル想定 ｜ 4本の解読線に異なるゲーム上の役割を与える盤面レイアウト

01 — 解読司令盤 / Command Board

A線を盤面上部の「出口」へ直結。B/Cは左右で全体の謎を掘り、Dは下部の保留領域へ置く。プレイヤーが一目で「今どこを突破すべきか」を認識できます。

推奨：最もゲーム盤らしい
A LINE COMPLETE → NEXT SCENE：目的地を確定

A線 — 次の場所を特定する【必須】

気づき末尾の4文字だけ規則が違う
→
資料旧市街の地図
→
仮説文字＝区画番号？
→
解読「北第三倉庫」

B線 — 暗号の意味を追う

気づき同じ語が過去資料にも存在
仮説これは単なる場所指定ではない

C線 — 発信者／背景を追う

資料10年前の研究記録
推察筆者は事件を予測していた？

D線 — 未分類／保留してよい

奇妙な一節「灯りを消すな」
未確認資料装置操作記録
仮説意味不明。後で再検討
設計意図：Aだけが物理的に「NEXT SCENE」へ接続。Dの将来的用途はプレイヤーへ明示しません。

02 — 四本の捜査線 / Four Tracks

4本を独立した横レーンとして管理。各線のパネルが左から「発見→資料→仮説→解読」へ進みます。スクリーンパネルを実際に移動させる遊びとの相性が最も高い案です。

03 — 分岐型推理ツリー / Decode Tree

ひとつの暗号文から4つの読み方が派生していく構造。同じ情報が別の意味を持つことを強調でき、暗号解読そのものを主役にできます。

05 — 多層解読盤 / Layered Cipher

「4つの別問題」ではなく、暗号文の意味を層状に剥がす案。Aを表層の実用情報、B/Cを意味・背景の深層、Dをまだ用途不明の最深層として扱います。

推奨：物語性
